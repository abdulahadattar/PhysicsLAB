# **App Name**: PhysicsLab

## Core Features:

- Interactive Simulations: Interactive physics simulations with adjustable parameters like mass, force, and angle, displaying dynamic feedback.
- Study Material Integration: Chapter-wise notes and solved MCQs for each class (Grades 9-12) aligned with the Sindh Textbook Board syllabus.
- Quizzes and Self-Assessment: Daily auto-generated quizzes with scoring and performance tracking to identify weak areas.
- Contextual Fun Facts: AI-powered tool to provide contextually relevant fun physics facts as the user interacts with the app. Unlocked facts can be class and topic specific.
- Teacher Dashboard: An offline-capable local admin panel for teacher (Abdul Ahad) to approve student accounts, view results, and send announcements.

## Style Guidelines:

- Primary color: A vibrant blue (#29ABE2) to represent the energy and dynamism of physics.
- Background color: Light blue (#E0F7FA), subtly desaturated, for a clean and calming interface.
- Accent color: A contrasting green (#90EE90) for interactive elements and key information, creating emphasis and visual interest.
- Clear and readable sans-serif font to ensure content is easily accessible. Use standard system fonts.
- Use simple, intuitive icons that visually represent physics concepts and functions. All icons to be in the same style.
- Clean, responsive layout to accommodate various screen sizes for optimal viewing experience on both desktops and mobile devices. Implement a grid system for consistency.
