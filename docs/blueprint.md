# **App Name**: PhysicsLab

## Core Features:
- **Interactive Simulations:** Engage with dynamic physics simulations that allow users to manipulate parameters like mass, force, and angle, providing real-time visual feedback.
- **Study Material Integration:** Access comprehensive chapter-wise notes and solved Multiple Choice Questions (MCQs) specifically tailored for Grades 9-12, aligning with the Sindh Textbook Board syllabus.
- **Quizzes and Self-Assessment:** Utilize the daily auto-generated quizzes with features for scoring and tracking performance to help identify areas needing improvement.
- **Contextual Fun Facts:** An AI-driven feature that delivers relevant and interesting physics facts as the user interacts with different parts of the application. These facts can be unlocked and are class and topic-specific.
- **Teacher Dashboard:** A dedicated section designed as an offline-capable local administration panel. This allows teachers (specifically Abdul Ahad in this instance) to manage student accounts (approve/deny), monitor student results and progress, and send out important announcements.

## Style Guidelines:

- Primary color: A vibrant blue (`#29ABE2`) to represent the energy and dynamism of physics.
- Background color: Light blue (`#E0F7FA`), subtly desaturated, for a clean and calming interface.
- Accent color: A contrasting green (`#90EE90`) for interactive elements and key information, creating emphasis and visual interest.
- Clear and readable sans-serif font to ensure content is easily accessible. Use standard system fonts.
- Use simple, intuitive icons that visually represent physics concepts and functions. All icons to be in the same style.
- Clean, responsive layout to accommodate various screen sizes for optimal viewing experience on both desktops and mobile devices. Implement a grid system for consistency.
